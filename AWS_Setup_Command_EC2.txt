## IAM ---> IAM Users ---> Create User ---> Attach Policies Direcly ---> "AmazonEC2ContainerRegistryReadOnly", "AmazonEC2ContainerRegistryPowerUse"

## Create ECR (Private One)

## ECR is an AWS Service (Managed Service)
## Here We Create one IAM User (with Permission of : "AmazonEC2ContainerRegistryReadOnly", "AmazonEC2ContainerRegistryPowerUse") in order to Access ECR from our VSCODE or EC2 Instance

## This Permission Generally allows image/repository management operations, including Deleting Images, but does not provide full administrative control such as creating or deleting ECR repositories.

Action	                 PowerUser

Pull image	                ✅

Tag images	                ✅

Delete repository	        ❌
Full ECR administration	    ❌
